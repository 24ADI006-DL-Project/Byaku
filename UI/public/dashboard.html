How each stage works
  1. Camera InputThe browser captures frames only after you start the live assistant or demonstration.
  2. YOLO Object DetectionThe configured detector proposes visible object classes and bounding boxes.
  3. ByteTrack TrackingTracking associates detections across processed frames when IDs are available.
  4. Depth Anything V2The depth model estimates relative near/far values, not metric distance.
  5. Spatial reasoningObject positions and relationships are derived from the current detections and depth output.
  6. Scene graphCurrent objects and supported relationships are represented as nodes and edges.
  7. Query reasoningThis stage runs for a user question; a camera frame alone does not make it ready.
  8. Scene description and narrationThe backend prepares scene text. The assistant page uses browser speech; this dashboard cannot confirm playback.
  9. Human review and correction memoryReview decisions are saved for audit and correction memory; they are not used to retrain the model.
